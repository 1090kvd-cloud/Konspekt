# Снимки экрана

Здесь лежит `dokument.jpg` — готовый документ, выгруженный из приложения. Он показан в описании репозитория.

Снимков самого приложения пока нет. Если хотите их добавить, нужны четыре, в таком порядке:

| Файл | Что снять |
|---|---|
| `1-forma.jpg` | Экран «Занятие»: свёрнутая строка предмета, поле темы, время |
| `2-konspekt.jpg` | Готовый конспект с полосой проверки сверху |
| `3-pravka.jpg` | Экран правки: учебный вопрос и кнопки «Разделить», «Слить» |
| `4-arhiv.jpg` | Архив, где хотя бы одно занятие отмечено проведённым — с зелёной полосой |

Если заведена программа подготовки, на первом снимке хорошо бы поймать блок «Следующее по программе» — он объясняет главную мысль приложения лучше любого текста.

## Как снять

На телефоне: кнопка питания и уменьшение громкости одновременно.

Перед съёмкой заполните настройки и соберите одно настоящее занятие — на пустых экранах смотреть нечего. Проверьте, что в кадр не попали служебные сведения: подразделение, фамилии, номер части.

Файлы весом больше мегабайта лучше уменьшить до ширины 720 точек.

## Как вставить в описание

После загрузки файлов замените блок «Как выглядит» в корневом `README.md` на таблицу:

```html
<table>
<tr>
<td width="25%"><img src="docs/1-forma.jpg" alt="Форма занятия"></td>
<td width="25%"><img src="docs/2-konspekt.jpg" alt="Готовый конспект"></td>
<td width="25%"><img src="docs/3-pravka.jpg" alt="Правка"></td>
<td width="25%"><img src="docs/4-arhiv.jpg" alt="Архив"></td>
</tr>
<tr>
<td align="center">Предмет, тема и время</td>
<td align="center">Конспект и нормоконтроль</td>
<td align="center">Правка учебных вопросов</td>
<td align="center">Архив с отметками</td>
</tr>
</table>
```
