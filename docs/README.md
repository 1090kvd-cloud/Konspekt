# Снимки экрана

Сюда положите четыре снимка с телефона под этими именами — они подставятся в README автоматически:

| Файл | Что снять |
|---|---|
| `1-forma.png` | Вкладка «Занятие»: выбран предмет, введена тема, видна разбивка времени |
| `2-konspekt.png` | Собранный конспект: шапка, учебные вопросы, ход занятия |
| `3-pechat.png` | Готовый документ — снимок из диалога печати или PDF на компьютере |
| `4-materialy.png` | Вкладка «Материалы» с парой приложенных методичек |

Снимок делается кнопками громкость вниз плюс питание. Лишнего в кадре быть не должно: фамилии, номера частей и подразделений замажьте или впишите условные.
