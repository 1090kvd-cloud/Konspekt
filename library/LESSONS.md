# База конспектов

Файл с готовыми занятиями. Собирается на компьютере, раздаётся по подразделению, загружается в приложение через **Архив → «Загрузить из файлов»**.

Это не то же самое, что `library.json`: там лежат заготовки формулировок по предметам, здесь — сами конспекты.

## Как получить рабочий файл

Не пишите с нуля. Соберите один конспект в приложении, сохраните в архив и нажмите **«Сохранить в файл»** — выгрузится вся база в этом формате. Дальше правьте и добавляйте занятия в любом текстовом редакторе.

`lessons-example.json` показывает структуру на одном занятии.

## Поля занятия

| Поле | Что это |
|---|---|
| `disciplineId` | Ключ предмета: `tactic`, `fire`, `drill`, `phys`, `regs`, `rhbz`, `topo`, `med`, `eng`, `comm`, `polit`, `tech`, `special`, `general`. |
| `themeNo` / `topic` | Номер и наименование темы — строка «ТЕМА N:». |
| `lessonNo` / `lessonTitle` | Номер и наименование занятия — строка «ЗАНЯТИЕ N:». |
| `minutes` | Продолжительность в минутах. Время в часах считается само, из расчёта 45 минут за час. |
| `timeLabel` | Необязательно. Своя запись времени, если стандартная не подходит. |
| `place` / `method` | Место и метод проведения. Пусто — подставятся типовые для предмета. |
| `customQuestions` | Учебные вопросы. Пусто — сформируются по предмету и теме. |
| `includeControl` / `includeSafety` / `includeHandout` | Что включать в комплект. |
| `edits` | Готовый текст разделов. Самое важное поле — см. ниже. |
| `note` | Примечания руководителя. |

Поля `id` и `createdAt` не пишите: приложение выдаёт свои при загрузке, поэтому один и тот же файл можно заливать повторно.

## Поле `edits` — содержание конспекта

Ключ раздела, значение — текст. Перевод строки `\n` разделяет пункты.

| Ключ | Раздел |
|---|---|
| `goals` | Цели занятия |
| `provision` | Материальное обеспечение |
| `safety` | Требования безопасности |
| `intro.content` / `intro.trainee` | Вводная часть: содержание и действия обучаемых |
| `q1.title`, `q1.content`, `q1.trainee` | Первый учебный вопрос; дальше `q2.`, `q3.` и так далее |
| `outro.content` / `outro.trainee` | Заключительная часть |
| `control` | Контрольные вопросы |

Чего в `edits` нет — приложение возьмёт из шаблонов предмета. То есть можно задать только цели и содержание первого вопроса, а остальное оставить на генератор.

Содержание пишется от первого лица: «Довожу», «Показываю», «Организую» — так стоит в стандартной форме. Строки, начинающиеся с таких глаголов, в раздаточный материал не попадают, туда идёт только фактический текст.

## Загрузка

Архив → «Загрузить из файлов». Приложение узнаёт базу конспектов по содержимому, а не по расширению, поэтому в одном заходе можно выбрать и `.json` с базой, и старые `.docx` — разберётся с каждым по-своему.

Загруженные занятия добавляются к имеющимся, ничего не затирая.
