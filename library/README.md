# Библиотека предметов

Приложение работает со встроенным набором предметов и не требует сети. Этот каталог — для тех, кто хочет вести свой набор формулировок: под конкретную часть, род войск или сложившуюся в подразделении форму документа.

## Как получить рабочий файл

Не пишите его с нуля. В приложении: **Настройки → Библиотека предметов → Сохранить файл**. Выгрузится весь текущий набор в этом же формате — его и правьте.

`example.json` показывает структуру на одном предмете.

## Поля

| Поле | Что это |
|---|---|
| `version` | Целое число. Обновление ставится, только если номер больше текущего. |
| `id` | Внутренний ключ предмета. Сохранённые в архиве занятия ссылаются на него — не меняйте у существующих. |
| `name` / `short` | Полное название для документа и короткое для кнопки. |
| `places` / `methods` | Варианты места и метода проведения, показываются чипами. |
| `eduGoals` / `upGoals` / `metGoals` | Учебные, воспитательные, методические цели. |
| `questions` | Заготовки учебных вопросов. Берутся по порядку, сколько запрошено. |
| `materials` / `references` / `safety` | Материальное обеспечение, руководства и пособия, требования безопасности. |
| `hints` | Три строки действий руководителя: изложение, тренировка, контроль. Попадают в ход занятия. |
| `handout` | Блоки раздаточного материала: `title` и `items`. |
| `control` | Контрольные вопросы. |

Подстановка `{t}` заменяется на тему занятия.

Обязательны только `id`, `name` и непустой `questions`. Остальное можно опустить — соответствующие разделы просто не попадут в документ.

## Как раздать

«Сохранить файл» → отправьте товарищу любым способом → у него «Загрузить файл». Мессенджер, Bluetooth, флешка — что угодно. Интернет не нужен, приложение его и не умеет.

Битый или неполный файл не ставится: приложение скажет, в каком предмете и каком поле ошибка, и останется на прежней библиотеке.
