# База конспектов

Файл с готовыми занятиями. Загружается в приложение целиком: **Архив → «Загрузить из файлов»**. Приложение узнаёт такой файл по содержимому, расширение значения не имеет.

Обратная выгрузка — кнопка **«Выгрузить базу»** там же. Она даёт файл в этом же формате: проще один раз выгрузить и править, чем писать с нуля.

## Что обязательно

Только `topic` или `lessonTitle` — хоть одно из двух. Остальное можно опустить, подставятся значения по умолчанию.

## Поля занятия

| Поле | Что это |
|---|---|
| `disciplineId` | Ключ предмета из библиотеки: `tactic`, `fire`, `drill`, `phys`, `regs`, `rhbz`, `topo`, `med`, `eng`, `comm`, `polit`, `tech`, `special`, `general`. |
| `themeNo` / `topic` | Номер и наименование раздела — строка «ТЕМА N:». |
| `lessonNo` / `lessonTitle` | Номер и наименование занятия — строка «ЗАНЯТИЕ N:». Номер может быть сдвоенным: `"3,4"`. |
| `minutes` | Продолжительность в минутах. По умолчанию 90. |
| `timeLabel` | Если нужно написать время иначе, чем считает приложение: `"2 часа"`. |
| `place` / `method` | Место и метод проведения. Пусто — возьмутся из библиотеки предмета. |
| `customQuestions` | Учебные вопросы. Пусто — сформируются по шаблонам предмета. |
| `includeControl` / `includeSafety` / `includeHandout` | Что вкладывать в комплект. |
| `note` | Примечания руководителя. |
| `edits` | Готовый текст разделов, см. ниже. |

`unitName`, `date`, `leader` лучше не заполнять: они подставятся из настроек того, кто загрузит файл.

## Готовый текст: `edits`

Ключ — раздел документа, значение — текст, где **строка соответствует пункту**.

| Ключ | Раздел |
|---|---|
| `goals` | Цели занятия |
| `provision` | Материальное обеспечение |
| `safety` | Требования безопасности |
| `intro.content` / `intro.trainee` | Вводная часть: содержание и действия обучаемых |
| `q1.title`, `q1.content`, `q1.trainee` | Первый учебный вопрос; дальше `q2.`, `q3.` и так далее |
| `outro.content` / `outro.trainee` | Заключительная часть |
| `control` | Контрольные вопросы |

Чего в `edits` нет — соберётся по шаблонам предмета. То, что есть, ляжет в документ дословно.

Перевод строки внутри значения записывается как `\n`.

## На что обратить внимание

Файл сохраняйте в UTF-8. Блокнот на Windows дописывает в начало невидимую метку — приложение её отбрасывает, но лучше пользоваться редактором, который так не делает.

При загрузке занятиям выдаются новые ключи, поэтому один и тот же файл можно залить дважды — получатся две независимые копии, а не перезапись.
