# План-конспект

Конструктор занятий для командира взвода. Вводите тему и время — получаете готовый комплект: план-конспект по установленной форме, раздаточный материал и контрольные вопросы.

Работает **полностью офлайн**. Ни одного разрешения, ни одного сетевого запроса. Всё хранится в памяти телефона.

## Что делает

- **План-конспект** — шапка с грифом утверждения, тема, учебные вопросы, цели (учебные, воспитательные, методические), руководства и пособия, материальное обеспечение, требования безопасности, ход занятия по трём частям с раздельными действиями руководителя и обучаемых.
- **Расчёт времени.** Вводная и заключительная части считаются от общей продолжительности, остаток раскладывается по учебным вопросам кратно пяти минутам. Разбивка видна прямо в форме, до сборки.
- **Раздаточный материал** — опорный конспект для обучаемых: тема, учебные вопросы, ключевые положения, алгоритм действий, место для записей.
- **Контрольные вопросы** — для опроса в заключительной части, с критериями оценки.
- **Правка текста.** Собранный документ можно править: каждый раздел — обычное поле, строка соответствует пункту. Правки живут вместе с занятием, у каждого поля есть возврат к шаблонному тексту.
- **Архив** — сохранённое занятие открывается повторно, тему можно поменять и пересобрать. Прошлый конспект копируется одной кнопкой и становится основой для следующего.
- **Серия занятий.** Тема одна, занятий шесть — вводите перечень наименований из программы и получаете сразу шесть заготовок в архиве, с общей шапкой и разными номерами.
- **Резервная копия** — архив, материалы, библиотека и настройки одним zip-файлом. При смене телефона не начинать заново.
- **Справочные материалы** — методичка, выписка из устава, таблица нормативов, фото плаката. Файл любого формата прикладывается к предмету и открывается системным просмотрщиком прямо с экрана конспекта.

Учебные вопросы можно не придумывать — они формируются по предмету и теме. Можно и вписать свои: тогда шаблонные не используются.

## Предметы обучения

Тактическая, огневая, строевая, физическая подготовка, общевоинские уставы, РХБ защита, военная топография, военно-медицинская, инженерная подготовка, связь, военно-политическая, техническая и специальная подготовка, плюс универсальный шаблон для всего остального. У каждого предмета свои формулировки целей, места и методы проведения, перечни пособий и требований безопасности.

## Справочные материалы

Отдельная вкладка. Прикладываете файл — PDF, Word, Excel, картинку, что угодно — и указываете, к какому предмету он относится (или отмечаете общим для всех). Файл копируется внутрь приложения, поэтому остаётся доступен, даже если исходный удалить или переставить.

На экране собранного конспекта появляется раздел «Материалы к занятию» со списком того, что приложено к этому предмету. Нажатие открывает файл той программой, которая на телефоне за него отвечает. В печатный документ и в отправку раздел не попадает — он только для подготовки.

Содержимое файлов приложение не разбирает: вытащить из методички формулировки для библиотеки оно не умеет и не пытается. Хранение и быстрый доступ — всё.

Материал можно переслать товарищу тем же способом, что и конспект.

## Библиотека предметов

Формулировки целей, вопросов, пособий и требований безопасности вынесены из кода в отдельный файл. Встроенный набор лежит внутри APK и доступен всегда. Поверх него можно положить свой:

«Сохранить файл» выгружает текущий набор, «Загрузить файл» принимает поправленный. Правят его на компьютере в любом текстовом редакторе, передают друг другу мессенджером или по Bluetooth.

Битый файл не ставится: приложение сообщит, в каком предмете и поле ошибка, и останется на прежней библиотеке. Кнопка «Вернуть встроенную» откатывает всё.

Формат и пример — в каталоге [`library/`](library/).

## Экспорт

Скопировать в буфер, отправить в мессенджер, выгрузить в Word (`.doc`, открывается и правится на компьютере), распечатать. В диалоге печати выбирается «Сохранить в PDF».

По умолчанию лист **альбомный**: ход занятия идёт одной таблицей — учебные вопросы и время, действия руководителя, действия обучаемых, — шапка таблицы повторяется на каждой странице. Цели, пособия и раздатка верстаются в две колонки, чтобы не оставалось пустого поля справа. Книжная ориентация переключается в настройках (там ход занятия разбивается по частям на таблицы в две колонки) либо прямо в диалоге печати.

## Сборка

APK собирается в GitHub Actions, локальная среда не нужна.

1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** — сборка запустится сама после первого push.
3. Через 3–5 минут APK лежит в артефактах прогона: `konspekt-apk` → `konspekt-debug.apk`.

Релизная сборка подписывается отладочным ключом, поэтому ставится на телефон без дополнительных действий. Для публикации в магазине подставьте свой keystore в `app/build.gradle.kts`.

Метка вида `v1.0` дополнительно прикладывает APK к релизу:

```bash
git tag v1.0 && git push --tags
```

### Локально

```bash
./gradlew assembleDebug
```

Нужны JDK 17 и Android SDK 34.

## Устройство проекта

```
app/src/main/java/ru/vzvod/konspekt/
├── data/Disciplines.kt   библиотека предметов и формулировок
├── data/Store.kt         архив и настройки в локальном JSON
├── logic/Generator.kt    сборка документа, расчёт времени
├── logic/Renderer.kt     вывод в текст и HTML для печати
├── ui/                   экраны на Jetpack Compose
└── MainActivity.kt
```

Чтобы добавить предмет или поправить формулировки, правьте только `Disciplines.kt` — остальное подстроится.
